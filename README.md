# WordPress & Shopify snippets by Path Digital Services

Tested code from real client work, used in tutorials on the [Path Digital blog](https://pathdigitalservices.com/post/).

Each file explains what it does and where it goes. Always test on a staging site first.

## Snippets
- `shopify/judge-me-product-schema-id.liquid`: connects Judge.me review ratings to your theme's Product schema using `@id`. Tutorial: [Best schema markup technique for SEO](https://pathdigitalservices.com/post/best-schema-markup-technique-seo/)
- `blocksy/order-blog-by-last-modified.php`: sorts the blog index and category archives by last modified date. NOTE: this is for themes that code Product JSON-LD without an "@id".
