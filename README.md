# WordPress & Shopify snippets by Path Digital Services

Tested code from real client work, used in tutorials on the [Path Digital blog](https://pathdigitalservices.com/post/).

Each file explains what it does and where it goes. Always test on a staging site first.

## Snippets

### Shopify
- `shopify/judge-me-product-schema-id.liquid`: connects Judge.me review ratings to your theme's Product schema using `@id`. Only for themes that hand-code Product JSON-LD without an "@id". Tutorial: [Best schema markup technique for SEO](https://pathdigitalservices.com/post/best-schema-markup-technique-seo/)

### Show updated posts first (WordPress)
- `blocksy/order-blog-by-last-modified.php`: sorts the blog index and category archives by last modified date (Blocksy or any theme).
- `elementor/order-loop-grid-by-last-modified.php`: sorts one Elementor Loop Grid by last modified date, using its Query ID.
- `divi/order-blog-module-by-last-modified.php`: sorts every Divi Blog Module by last modified date.
- `divi/show-last-modified-date.php`: shows the last modified date in place of the published date.
- - `divi/show-last-modified-date-post-title-byline.php`: shows the last modified date in the Divi Post Title module's byline.
- `advanced-post-block/show-last-modified-date.php`: shows the last modified date on Advanced Post Block cards.
